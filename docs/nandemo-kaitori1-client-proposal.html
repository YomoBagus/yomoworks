Web Performance Assessment

表示速度改善　対応方法一覧

nandemo-kaitori1.com のページ表示速度を Google PageSpeed Insights で 90 点以上にするための、対応方法とその効果・作業量の整理です。

  • 対象　nandemo-kaitori1.com
  • 目標　モバイル 90 点以上
  • サーバー　エックスサーバー（共用）
  • 構成　静的 HTML（確定）
  • 作成日　2026-09-01

サイト構成の確認結果

ご確認の結果、トップページは WordPress ではなく、直接作られた HTML ファイルであることが確定しました。

高速化プラグイン「WP Rocket」は WordPress が生成するページにのみ働く仕組みのため、静的 HTML のトップページには構造上そもそも適用できません。あわせて、今回は WP Rocket 自体を使用しない方針で確定しています。

ご安心ください。下記 A〜E の施策は、いずれも有料プラグインを必要としません。エックスサーバーの標準機能とサイト本体の改修のみで、目標である「トップページ 90 点」を目指せます。追加のプラグイン費用は発生しません。

1

90 点の内訳

PageSpeed のスコアは 5 つの指標の加重平均です。配点は以下の通りで、「表示の速さ」だけでなく「操作できるまでの待ち時間」と「画面のガタつき」で 55% を占めます。画像を軽くするだけでは 90 点には届きません。

TBT 30% LCP 25% CLS 25% FCP 10 SI 10

※ スマートフォン計測は低速回線・低速CPUを想定した厳しい条件で行われます。

指標意味合格ライン
TBTページが操作できるようになるまでの待ち時間200ms 以下
LCPメインの画像・見出しが表示されるまでの時間2.5 秒以下
CLS読み込み中に画面がガタつく量0.1 以下
FCP最初に何かが表示されるまでの時間1.8 秒以下
SI全体が表示され終わるまでの体感速度3.4 秒以下

対応方法一覧

効果・工数は現時点での想定です（実測前のため）。着手前の計測結果によって前後する場合があります。

0 ── 事前確認

必須
0-1
サイト構成の確認

トップページは静的 HTML であることを確認済みです。WordPress 用の高速化プラグインは適用対象外と確定しました。

完了
0-2
現状スコアの計測（基準値の記録）

作業前の点数と各指標を記録します。これがないと、どの作業が何点効いたかを判断できません。

効果 前提工数 小

A ── サーバー設定（サイトの改修なし）

A-1
Xアクセラレータ Ver.2 を有効化

エックスサーバーの標準機能。ファイル配信とプログラム処理を高速化します。管理画面の操作のみ。

効果 中工数 小
A-2
ブラウザキャッシュ設定を有効化

一度見た画像などを訪問者の端末に保存させ、2 回目以降の表示を速くします。

効果 中工数 小
A-3
XPageSpeed（ファイル圧縮・WebP変換）を有効化

データを圧縮して転送量を減らします。ただし「CSS/JavaScript の遅延読み込み」機能は表示崩れの報告が多いため、あえて使いません。

効果 中工数 小要検証
A-4
サーバー設定ファイルで圧縮・保存期間を明示

管理画面の設定に加えて、設定ファイル側でも圧縮方式とキャッシュ期間を指定し、確実に効かせます。

効果 中工数 小

B ── 画像の最適化

最優先
B-1
画像を実際の表示サイズまで縮小

買取サイトは商品・実績写真が多く、ここが最大の負荷になりがちです。スマホ幅の枠に大きすぎる写真が入っていないか点検し、適正サイズに作り直します。

効果 大工数 中
B-2
画像を WebP 形式に変換

見た目を保ったままファイル容量を 25〜35% 程度削減できる新しい画像形式に変換します。

効果 大工数 中
B-3
最初に見える画像を優先的に読み込む

一番上のメイン画像に優先指定を付け、真っ先に読み込ませます。LCP に直結します。

効果 大工数 小
B-4
画面外の画像は後から読み込む（遅延読み込み）

スクロールして初めて見える画像は、そこまで読み込みを待たせます。初期表示が大幅に軽くなります。

効果 大工数 小
B-5
全画像に縦横サイズを指定

画像の表示枠をあらかじめ確保し、読み込み中に文字がずれる現象を防ぎます。配点 25% の CLS に直接効きます。

効果 大工数 中

C ── 文字・フォント

C-1
日本語 Web フォントを端末標準フォントに変更

日本語の Web フォントは 1 種類で数 MB になることがあり、単体で致命傷になり得ます。端末に元から入っている書体に変えると転送量はゼロになります。文字の見た目の印象は変わります。

効果 大工数 小要相談
C-2
アイコン用フォントを画像（SVG）に置き換え

数個のアイコンのために大きなフォント一式を読み込んでいる場合、見た目そのままで数百 KB 削減できます。

効果 中工数 中

D ── プログラム（JavaScript）の軽量化

配点最大
D-1
スクリプトの読み込みを後回しにする

ページの表示をブロックしていた処理を、表示後に回します。配点 30% の TBT に効きます。

効果 大工数 小
D-2
アクセス解析・広告タグを操作後に実行

解析タグや広告タグを、訪問者が画面を触るまで待たせます。計測される数値がわずかに減る可能性があります（要ご判断）。

効果 大工数 小要相談
D-3
スライダー等のプラグインを軽量化・見直し

トップのスライドショーなどが重い処理の主因であることが多く、軽い実装に置き換えます。動きの仕様が変わる場合があります。

効果 大工数 大要相談

E ── デザイン指定（CSS）の軽量化

E-1
最初の表示に必要な分だけ先に読み込む

画面上部の表示に必要な指定だけを先に読み込み、残りを後回しにします。表示開始が早くなります。

効果 中工数 大
E-2
使っていないデザイン指定を削除

既製テンプレート由来の未使用部分を整理します。実際に使われているのは全体の 1 割程度ということも珍しくありません。

効果 中工数 中

F ── WordPress 部分（/wp/ のブログ）

トップページ対象外

この F の項目は /wp/ 配下のブログ記事にのみ効きます。今回の目標である「トップページ 90 点」には影響しません。ブログを継続される場合の任意項目としてご検討ください。いずれも有料プラグインは不要です。

F-1
エックスサーバーの「サーバーキャッシュ設定」を有効化

サーバーの標準機能でブログ記事の表示を速くします。プラグインの追加は不要で、費用もかかりません。

効果 中工数 小
F-2
画像圧縮プラグインの導入

記事内の画像を自動で圧縮します。無料のプラグインで対応可能です。

効果 中工数 小
F-3
不要プラグインの整理

使っていないプラグインが全ページに独自のファイルを読み込ませている場合があり、停止するだけで軽くなります。

効果 中工数 小

G ── 追加でご検討いただきたい項目

任意
G-1
CDN（配信高速化サービス）の導入

現在 CDN は未導入です。福岡中心の集客であれば必須ではありませんが、導入すれば画像配信と応答速度を底上げできます。

効果 中工数 中
G-2
更新の止まっている WordPress の扱い

/wp/ のブログは 2021 年以降ほぼ更新されていないようです。放置された WordPress はセキュリティ上のリスクになります。継続・停止のご判断をお願いします。

速度対象外
G-3
よくある質問ページの URL 変更

/q&a.html は URL に記号「&」を含み、共有・計測・検索エンジンで不利になります。改修のついでの変更を推奨します。

速度対象外
3

進め方

効果と安全性の高いものから順に着手し、1 段階ごとに計測して効果を確認します。

  1. 現状計測（0-2）　── 構成確認（0-1）は完了済みです。作業前の点数を記録し、効果測定の基準にします。
  2. サーバー設定（A-1〜A-4）　── サイトの改修を伴わず、リスクが低く即効性があります。
  3. 画像の最適化（B-1〜B-5）　── 最も効果が大きい工程です。
  4. フォントの見直し（C-1 / C-2）　── 見た目に関わるため、事前にご確認いただきます。
  5. JavaScript の軽量化（D-1〜D-3）　── 配点最大の TBT を改善します。
  6. CSS の軽量化（E-1 / E-2）　── 90 点到達に向けた仕上げです。
  7. 動作確認と再計測　── 電話・LINE・フォームの導線を実機で確認します。

2〜5 の段階でモバイル 80 点前後、6 まで完了で 90 点以上が現実的なラインです。

4

事前にご了承いただきたい点

  • 点数は計測ごとに ±5 点程度変動します。1 回の結果では判断せず、5 回計測した中央値で達成を判定します。
  • アクセス解析の数値がわずかに減る可能性があります。D-2 を実施した場合のトレードオフです。実施の可否はご判断ください。
  • フォントを変更すると文字の印象が変わります。C-1 は効果が大きい一方で見た目に影響するため、変更前後を比較のうえご判断いただきます。
  • スマートフォンの 90 点は相応の作業量が必要です。設定を数か所 ON にするだけでは届きません。パソコン表示の 90 点は比較的容易です。
  • 点数より、お問い合わせ導線が正常に動くことを優先します。作業後は電話発信・LINE・フォーム送信を実機で必ず確認します。
  • 検索順位に実際に影響するのは、実ユーザーの計測値です。90 点というスコアは改善の指標であり、順位を直接保証するものではありません。
